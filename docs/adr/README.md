# Architecture decision records

The decisions that shape HR Agency, reverse-engineered on 2026-10-02 from the commit history, the code and the
implementation plans written while it was built. Each record gives the context, the decision as something you can check
against the code, the alternatives that left evidence, the consequences (including the traps learned the hard way),
the commits that put it in place, and when to revisit it.

A new decision starts from [`TEMPLATE.md`](TEMPLATE.md) with the next free number; a changed decision gets a new record
that supersedes the old one, which stays.
